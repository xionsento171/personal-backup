Personal Backup

Personal Backup is a private, single-user tool. It keeps an encrypted backup copy of its owner's files in the owner's own Google Drive.

Files are encrypted before they are uploaded; Google only stores the encrypted copy. The tool uses only the Google Drive permission to create and manage its own files; it cannot see, open or change any other file in Google Drive.

Personal Backup is not a public service. It has no other users and offers no sign-up.
