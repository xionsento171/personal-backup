Privacy policy

Personal Backup · last updated 6 November 2026

Who uses it

Personal Backup is a private tool used by one person, its owner, for the owner's own files. It has no other users. Nobody else's data is collected or processed.

What Google data it accesses

The tool asks for a single Google permission: See, edit, create and delete only the specific Google Drive files you use with this app (drive.file). With it, the tool can only work with the files and folders it created itself. It cannot see, read or change any other file, and it does not access email, contacts, calendar or any other Google service.

How the data is used

  • Files are encrypted before upload; Google stores only the encrypted copy.
  • The Google sign-in token is stored only on the owner's own device, to keep the backup running.
  • Nothing is shared with, sold to or transferred to anyone. No data is used for advertising, analytics or to train any model.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The backup files stay in the owner's Google Drive under the owner's control. Access can be withdrawn at any time in the Google Account under Security → Third-party apps & services; the stored token then stops working.

This website

These pages are static, set no cookies and contain no tracking. They are hosted on GitHub Pages; see GitHub's privacy statement for its server logs.
